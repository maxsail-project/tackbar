# TackBar v0.6.4 Manual Production Validation

**Release:** v0.6.4  
**Status:** Pending production validation  
**Environment:** production  
**Application:** https://app.tackbar.eu  
**Purpose:** Validate the implemented Sailor activation welcome-email flow and
the explicitly included release-package fixes after the immutable tag is
deployed.

This checklist records work that must happen after the human creates and deploys
the immutable `v0.6.4` tag. It does not claim that deployment or production
validation has already happened. Do not commit credentials, capability tokens,
real email contents or other personal data here.

## Deployment and configuration

- [ ] Confirm production checkout is at immutable tag `v0.6.4`.
- [ ] Confirm checkout is detached from a moving branch.
- [ ] Confirm the production working tree is clean.
- [ ] Verify release identity with `git describe --tags --always`.
- [ ] Confirm existing `/etc/tackbar/tackbar.env` is preserved.
- [ ] Confirm existing OVH IMAP variables remain configured.
- [ ] Confirm required OVH SMTP variables are configured outside Git.
- [ ] Confirm `TACKBAR_PUBLIC_BASE_URL=https://app.tackbar.eu`.
- [ ] Ensure no credential is printed during validation.
- [ ] Rebuild the frontend because v0.6.4 contains frontend changes.
- [ ] Publish frontend build output to the Caddy-served directory.
- [ ] Restart `tackbar.service`.
- [ ] Confirm the backend service reports healthy state.
- [ ] Confirm `GET http://127.0.0.1:8000/health` returns:

```json
{"status":"ok","service":"tackbar"}
```

Do not reinstall dependencies unless manifests changed and the runbook requires
it.

## Failure semantics

If SMTP failure occurs naturally, expected behavior is:

- Sailor remains `ACTIVE` and consent remains authoritative;
- Personal TackBar remains unchanged;
- Session capability state remains unchanged;
- Admin records a safe failure indication;
- Admin can retry explicitly when eligible.

Validate this when practical without disrupting production. Forced destructive
failure testing is optional and must not be performed when operationally unsafe.
