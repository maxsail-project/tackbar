# TackBar v0.6.3 — Touch Chart Zoom Fix Requirements

**Status:** Delivered  
**Baseline:** TackBar v0.6.2 — Viewer & Admin Usability  
**Scope:** focused mobile/tablet correction for visual temporal chart zoom

---

## 1. Objective

Restore reliable local visual temporal zoom for the existing Session Viewer
time-series charts on touch, stylus and mouse input without changing the
delivered v0.6.2 analysis model.

## 2. Delivered pointer behavior

`MetricChart` and the Individual Analysis dual-axis SOG + COG chart use one
Pointer Events selection path. A press inside the chart starts a temporary
selection, horizontal movement extends it, and release applies one local zoom
range to the chart's shared GPS/UTC X axis.

The chart captures the active pointer while selecting. Pointer cancellation,
uncaptured leave and capture loss clear the temporary selection without applying
a zoom. `touch-action: pan-y` remains scoped to the chart canvas so vertical
page scrolling remains available.

Each chart keeps its own presentation-only zoom and Reset action. Two Individual
Analysis Activity charts therefore remain independent.

## 3. Preserved semantics

v0.6.3 preserves:

- the shared Analysis Window and filtered sample set;
- map, Summary, replay and shared `playbackTime` behavior;
- normal comparison-chart behavior;
- one dual-axis individual SOG + COG chart per selected Activity;
- SOG/COG axes, colors, missing-value behavior and COG circular semantics;
- frontend/backend API contracts and JSON/filesystem persistence.

## 4. Non-goals

This corrective release does not add persisted zoom, saved segments, new metrics,
new replay behavior, backend changes, API changes, database changes or a broader
Viewer redesign.

## 5. Validation summary

Focused temporal zoom and Individual Analysis tests passed, including the shared
pointer timestamp and selection lifecycle. Frontend typecheck and production
build passed. `actions/checkout@v5` is used by the deployment workflow. Full
repository regression and production deployment are separate validation work.
