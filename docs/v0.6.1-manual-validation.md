# TackBar v0.6.1 — Manual Production Validation

**Status:** PASS

## Purpose

Record the operator-confirmed production validation used to close TackBar v0.6.1.

No contemporaneous step-by-step test checklist was retained during the cutover. This document records the validated outcomes confirmed immediately after the deployment and production test; it does not claim a more detailed execution log than actually exists.

---

## Validated production configuration

The deployed production baseline was confirmed as:

- application release tag: `v0.6.1`;
- backend service: `tackbar.service`;
- runtime data root: `/var/lib/tackbar/data`;
- mailbox provider: `ovh`;
- mailbox: `share@tackbar.eu`;
- IMAP host: `imap.mail.ovh.net`;
- IMAP port: `993`;
- mailbox credentials supplied through `/etc/tackbar/tackbar.env`;
- credentials and Admin secret kept outside the repository;
- backend health endpoint returned `{"status":"ok","service":"tackbar"}` after restart.

---

## Manual validation outcomes

The operator confirmed the following as PASS:

1. Production loaded the OVH runtime configuration from `/etc/tackbar/tackbar.env`.
2. `TACKBAR_MAILBOX_PROVIDER=ovh` was visible in the running backend environment.
3. A real supported Vakaros track email was received by `share@tackbar.eu`.
4. Admin **Review mailbox now** successfully reviewed the OVH mailbox.
5. The real message entered the existing TackBar ingestion pipeline.
6. The ingestion produced the expected Sailor, Activity and Session results.
7. The resulting Session was usable through the existing Viewer flow.
8. The OVH production path operated without Gmail OAuth or Gmail refresh-token renewal.
9. The production runtime dataset was intentionally reset during the cutover and TackBar restarted cleanly with the expected `tackbar:tackbar` runtime-data ownership.
10. A second clean reset was performed after exploratory mailbox messages were removed, leaving the pilot ready to rebuild only from the intended valid tracks.

The effective end-to-end production path was therefore validated as:

```text
real email
→ share@tackbar.eu
→ OVHcloud Zimbra / IMAPS
→ OVH adapter
→ InboundEmail
→ existing ingestion pipeline
→ Sailor
→ Activity
→ Session
→ existing Viewer
```
