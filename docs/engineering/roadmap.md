# TackBar Engineering Roadmap

This is a proposed, non-normative adoption path for the [maturity model](maturity.md), based on the [engineering assessment](assessment.md) of local `main` at `1d9a4c1404b2171a30a7b113ff2b56873e2cbd44`. The highest evidenced cumulative level is L2; the near-term objective approved in [#230](https://github.com/maxsail-project/tackbar/issues/230) is to consolidate L3 — Governed. Each increment below requires its own scoped Issue decisions and authorization before implementation. This document does not change [AGENTS.md](../../AGENTS.md), product contracts, Git permissions, or release authority.

The [Product Roadmap](../../ROADMAP.md) concerns the sailing product. This complementary roadmap concerns how TackBar is designed, developed, tested, governed, and maintained. Both use small Issues, evidence, and review. Continue normal product work while improving the engineering method.

## Prioritized adoption increments

| **3. Run a contributor onboarding and tool-portability check.** Use a clean session and, when available, a new human contributor with their own authorized AI tool on one representative, bounded Issue. | L3 adoptability and cross-platform use are [not verified](assessment.md#capability-assessment). Reassess L3 only after applicable criteria have direct evidence. |

## Later directions

Reusable skills or additional agent coordination may be useful when repeated work proves the need and a single-source procedure can be tested across tools. Measured experiments may later compare similar increments and check outcomes. These are L4 and L5 directions, not commitments, prerequisites for product work, or targets that justify new infrastructure by themselves. Preserve continuity and minimalism: improve the existing harness and method before adding abstractions.

Record actual evidence and an assessed SHA in [assessment.md](assessment.md) when the baseline changes. Keep pending work and authorization in GitHub Issues, with [#230](https://github.com/maxsail-project/tackbar/issues/230) coordinating this initiative; the roadmap does not grant permission to implement its proposals.
